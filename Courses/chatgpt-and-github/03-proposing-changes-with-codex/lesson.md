Welcome back to Runtime Republic. So far, ChatGPT has been reading. Today we talk about changing things. Remember, ChatGPT's GitHub app is read-only. To write code or open pull requests, OpenAI points users to a separate tool called Codex.

A pull request is a proposal: here's what I want to change, and why. Nothing reaches the main version until a person with authority reviews it and says yes. That's the most important rule in this series. The AI proposes. A human decides. Not the assistant, and not the person who asked it, but the person accountable for the project.

You don't need Codex to take part. The simplest way to propose a change is to have ChatGPT draft it, then submit it yourself as a comment, an issue, or a pull request. Here's a prompt. Say or type: "Draft a suggested change to this clause. Show the old text and the new text side by side, and explain the reason in two sentences, with a source."

If you do use Codex, three habits keep the work honest.

First, keep changes small. Say: "Make one change only. Don't touch any other file." Small proposals are easy to review and easy to undo.

Second, ask for a self-check. Say: "Before you open the pull request, list what you changed, what you checked, and anything you weren't sure about."

Third, read every line before it's merged. An AI can be confidently wrong. A pull request makes the work visible. Only a careful human makes it trustworthy.

Why go through all this? Because a pull request leaves a record. Months later, anyone can see who proposed a change, what it was, why, and who approved it. That's exactly the kind of open record the One-Hour Rule series argues every bill deserves.

One more thought. Claude and ChatGPT can work on the same project. One can draft, the other can review, and you decide. Different tools catch different mistakes. What matters is that every change is public, explained, and approved by a person.

Let's recap. ChatGPT's GitHub app reads. Codex can propose changes through pull requests. Keep changes small, ask for a self-check, and read every line. And the AI proposes, a human decides.

That's the series. You can now connect ChatGPT, read a project, and propose a change the right way.
