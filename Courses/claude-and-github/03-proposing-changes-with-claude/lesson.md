Welcome back to Runtime Republic. So far, Claude has been reading. Today it helps you write. But first, an important point: the GitHub connector we set up is for reading files. To actually make changes in a repository, Anthropic offers a separate tool called Claude Code.

Claude Code can read a project, make edits on a separate branch, and open a pull request. A pull request is a proposal: here's what I want to change, and why. Nothing reaches the main version until a person with authority reviews it and says yes.

That's the most important rule in this whole series. The AI proposes. A human decides. Not the assistant, and not the person who asked it, but the person accountable for the project.

You don't need Claude Code to take part, though. The simplest way to propose a change is to have Claude draft it, and then submit it yourself as a comment, an issue, or a pull request. Here's a prompt for that. Say or type: "Draft a suggested change to this clause. Show the old text and the new text side by side, and explain the reason in two sentences, with a source."

If you do use Claude Code, three habits keep the work honest.

First, ask for small changes. Say: "Make one change only. Don't touch any other file." Small proposals are easy to review and easy to undo.

Second, ask it to check its own work. Say: "Before you open the pull request, list what you changed, what you checked, and anything you weren't sure about."

Third, read every line before it's merged. Claude can be confidently wrong. A pull request makes its work visible, but only a careful human makes it trustworthy.

Why go through all this? Because a pull request leaves a record. Months later, anyone can see who proposed a change, what it was, why, and who approved it. That's exactly the kind of open record the One-Hour Rule series argues every bill deserves.

Let's recap. The GitHub connector reads. Claude Code can write, on a branch, through a pull request. Keep changes small, ask for a self-check, and read every line. And remember: the AI proposes, a human decides.

That's the series. You can now connect Claude, read a project, and propose a change the right way.
