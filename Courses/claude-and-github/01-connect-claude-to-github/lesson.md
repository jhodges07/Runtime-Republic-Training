Welcome to Runtime Republic. This short series shows how to set up Claude, the AI assistant made by Anthropic, to work with GitHub. By the end, you'll be able to point Claude at a public project, like the One-Hour Rule draft bill, and ask it good questions.

First, a reminder of why this matters. GitHub is where a growing number of public projects live: drafts, rules, research, and the record of every change. Reading a project can feel like walking into a library with no librarian. Claude can be that librarian.

Here's the setup, in plain steps. Menus change over time, so look for these words rather than exact positions.

Step one. Have a GitHub account. It's free. Claude's GitHub connector asks you to sign in to GitHub, even to read public projects.

Step two. In Claude, open your settings and find the connectors, sometimes called integrations. Turn on GitHub. Claude will send you to GitHub to sign in and approve access. What you can use may depend on your plan.

Step three. Decide where to use it. In a single chat, press the plus button and choose Add from GitHub, then pick the files or folders you want Claude to read. Or, for work you'll come back to, create a Claude Project and add the repository to the project's knowledge. That way every chat in the project can see it.

One thing to know. Claude reads a snapshot of the files. It doesn't update on its own. When the project changes, press sync in your Claude Project to pull in the latest version. Do that before any important review.

Also know what Claude can see. It sees only the repositories you allow, and private ones only if you have access. If a private repository won't load, its owner may need to grant access to the Claude app on GitHub. Start with public projects. They're the easiest place to practice, and reading changes nothing, so you can't break anything by exploring.

And a first prompt to try, once it's connected. Say or type: "Read this repository and explain, in plain words, what it is for, who it's for, and where a newcomer should start."

Let's recap. Get a GitHub account. Turn on the GitHub connector in Claude's settings and approve access. Add files to a chat, or a whole repository to a Claude Project. And remember to sync before each review.

Next time, we'll put Claude to work reading a project, with prompts that find what matters and flag what's missing.
