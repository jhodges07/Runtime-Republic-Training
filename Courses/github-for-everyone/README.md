# GitHub for Everyone

A seven-part series written to be listened to. It starts at a 10-year-old's level and
builds up: what GitHub is, where it came from, how its tools work, open source, AI helpers,
and how the same tools could help voters and legislators write a bill and stay informed about it.

It teaches people with no GitHub experience how to work together online, without meeting
at the same time, to advance the ideals of the AGCL.
