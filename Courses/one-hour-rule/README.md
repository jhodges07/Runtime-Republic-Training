# The One-Hour Rule

A five-part series written to be listened to. It proposes that no Kansas bill may be
introduced, amended, voted on or signed unless its exact text has been public in an
official repository for at least one hour, and asks how office holders can use public
repositories without breaking the Kansas Open Meetings Act.

This is a proposal for discussion, not an adopted framework rule and not legal advice.
Civic and non-partisan: it argues for a process, not for any party's bills.
