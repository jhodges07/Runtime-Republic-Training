# Reading the Draft

A Long series (10–12 minute essays) that reads model legislation aloud, clause by clause:
what each part says, why it is there, and where it is still weak.

The drafts discussed are models for discussion. They are not introduced bills, not law,
and not legal advice. Engineering of the underlying package is tracked separately as a
proposed project in the Legislative-Manager repository.
