# GitHub & Asynchronous Collaboration

Status: Planned — no lessons yet

Teaches people with no GitHub experience how to work together online without meeting
at the same time, each with their own AI assistant, to advance the ideals of the AGCL.

## Proposed lessons

Proposed only; the Human Engineer sets the final list and order.

1. What a repository is, and why it works as a town hall that never closes
2. Issues: turning a question or task into a unit of work
3. Branches and pull requests: proposing a change, debating it, approving it
4. Shared rules for people and AI: control documents and CLAUDE.md
5. Habits for asynchronous work: write it down, write for the stranger, hand off cleanly
6. A cadence for group decisions: calls for proposals, review dates, published summaries

Builds on [Building With Claude, Lesson 05](../building-with-claude/05-the-asynchronous-republic/lesson.md).
