# NBBF — Node-Based Budget Framework

Status: Planned — no lessons yet

fiscal exit conditions, and sunset and renewal mechanics.

Canonical source: [NBBF-Control-Documents](https://github.com/jhodges07/NBBF-Control-Documents).
