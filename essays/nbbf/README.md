Plain-language essays that explain the Node-Based Budget Framework (NBBF) control documents.

- **Control documents:** [NBBF-Control-Documents](https://github.com/jhodges07/NBBF-Control-Documents)
- **Rule:** essays explain; control documents govern. If an essay and a control
  document disagree, the control document wins (CONTROL 10).
- Every essay here names the control documents it explains in a
  `Governing sources` header line.
